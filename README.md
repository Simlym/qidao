# 棋岛 QiDao

**中国象棋 × 揭棋｜对弈 · 训练 · 复盘**

**练会一道题，再把它用到下一盘棋里。**

棋岛是一款面向棋类爱好者的多端对弈与训练工具，支持 **中国象棋（Xiangqi）** 和 **揭棋（Jieqi）** 两种玩法。既能与引擎对弈、研究局面，也能通过训练和复盘发现自己的薄弱环节。

| 中国象棋 · Xiangqi | 揭棋 · Jieqi |
| --- | --- |
| ![棋岛中国象棋人机对弈界面](docs/pc-play-optimized.png) | ![棋岛揭棋对弈界面](docs/pc-jieqi-docked.png) |
| **对弈、战术训练与复盘**：人机对弈、每日题库、间隔复习、闯关、棋谱复盘和教练建议。 | **对弈与局面分析**：揭棋人机对战、自由翻子、专用引擎分析；暗子揭开带来不同的判断与变化。 |

> **目前处于开发阶段。** 官方体验网站和正式客户端安装包尚未发布；现阶段可通过自行部署体验。中国象棋训练功能相对完整；揭棋当前侧重对弈与分析，并非已支持全部象棋训练功能。

## 核心功能

**每天打开，知道先练什么。** 中国象棋的「今日」会安排新题和到期复习。答错的题会再次出现，熟悉的题逐渐拉长复习间隔。

**哪里薄弱，就练哪里。** 按杀法、开局、中局、残局选择专项，也可以通过闯关逐步挑战。遇到难题先看提示，再尝试自己算出后续着法。

**两种棋，一样能深入研究。** 中国象棋支持人机对弈、保存棋谱并复盘关键失误；揭棋支持人机对战和自由翻子，并可连接揭棋专用引擎分析局面。两种玩法使用独立的引擎配置。

**看见自己的变化。** 中国象棋成长报告展示训练正确率、棋力评分和薄弱类目。教练会结合训练记录给出建议；所连接的服务开启 AI 后，还可提供讲解与复盘报告。

## 第一次使用，从这一轮开始

启用本地引擎后，游客可以直接离线对弈；题库训练、闯关、学习计划与 AI 服务需要注册登录并联网使用：

1. 注册登录并连接服务器，在“今日”完成一组推荐题。
2. 遇到错题，跟随提示重算，之后按提醒复习。
3. 到“对弈”下一盘棋，结束后在“我的棋局”中复盘。
4. 看看“成长报告”，为下一次训练选一个薄弱专项。

训练进度保存在所连接服务器的账号下；本地棋谱可在登录后主动认领并同步。遇到疑似错题或其他可行解，可在训练页反馈，并在设置中查看处理回复。更多操作见[使用指南](docs/USER_GUIDE.md)。

## 在哪里使用

| 方式 | 怎么用 | 目前的情况 |
| --- | --- | --- |
| 浏览器 | 打开服务提供者给出的网址，电脑和手机均可访问；浏览器支持时可添加到桌面 | 支持自行部署体验，官方体验网站尚未开放 |
| Windows 客户端 | 安装后打开，使用随客户端预设的服务；想加强本机棋力时，可在设置中下载安装象棋引擎 | 已有客户端实现，正式安装包尚未发布 |
| Android 客户端 | 安装应用后连接服务，在手机上训练和对弈 | 仍在开发与设备验证阶段，尚未正式发布 |

客户端需要连接服务才能使用账号、题库和训练记录。日常使用无需自己搭建服务器；目前尚无官方服务，可连接自行部署的实例。

## 账号、收费与自己的服务器

**收费计划。** 客户端免费使用，AI功能需要消耗token，考虑套餐形式收费。当然也可以完全自己部署，用自己的api key。当前项目尚未开放付费购买，正式套餐、价格和权益会在上线前公布。

**AI 讲解按需使用。** 基础训练与规则教练不要求开启 AI。AI 讲解由所连接的服务提供，需要登录并有可用额度；可在“设置 → 账户与 AI 额度”查看。训练奖励积分和 AI 额度分别计算。

**象棋离线对弈与补传。** 安装并启用本地引擎后，可离线完成人机对弈。每个完整回合自动保存到本机，在对弈首页的“本机对局”继续；已完成棋谱连接原服务器、登录原账号后自动补传。游客棋谱需主动认领。补传需要新版服务器，旧版服务器会保留待同步记录。清除应用或浏览器数据会删除本机记录。题库训练统一在线使用，不提供离线题包；揭棋暂未接入这套离线同步流程。

**支持自己的服务器。** 在“设置 → 服务器（高级）”连接自建服务，也可恢复客户端的默认服务。不同服务器的账号、训练记录和棋谱各自独立，切换不会自动搬迁数据。操作步骤见[使用指南](docs/USER_GUIDE.md#连接自己的服务器)。

> **项目命名说明：** 对外品牌现为「棋岛 QiDao」；GitHub 仓库、安装标识和部分内部包名暂沿用历史名称 `xiangqidao`，以保持既有客户端、接口与开发脚本兼容。详见[客户端构建与标识说明](docs/development/build-clients.md#qidao-品牌与历史应用标识)。
