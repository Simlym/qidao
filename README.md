# 象棋道 Xiangqidao

**练会一道题，再把它用到下一盘棋里。**

象棋道是一款面向象棋爱好者的训练与复盘工具。做题练计算，实战找问题，再把漏算的局面变成下一次练习——让训练围绕自己的弱点展开。

如果你常常觉得“这道题做过，实战还是看漏”，或是下完一盘棋却不知道该练什么，可以从这里开始。

![象棋道人机对弈界面](docs/pc-play-optimized.png)

> **目前处于开发阶段。** 官方体验网站和正式客户端安装包尚未发布；现阶段可通过自行部署体验。下方列出了各端的准备情况。

## 在这里，你可以怎样练棋

**每天打开，知道先练什么。** “今日”会安排新题和到期复习。答错的题会再次出现，熟悉的题逐渐拉长复习间隔，帮助你把棋形记牢。

**哪里薄弱，就练哪里。** 按杀法、开局、中局、残局选择专项，也可以通过闯关逐步挑战。遇到难题先看提示，再尝试自己算出后续着法。

**下一盘，再回头看看。** 与电脑对弈，选择先后手和难度；结束后保存棋谱、查看关键失误，把值得重练的局面收入个人题库。

**看见自己的变化。** 在成长报告中查看正确率、棋力评分和薄弱类目。教练会结合训练记录给出建议；所连接的服务开启 AI 后，还可提供棋理讲解与复盘报告。

标准象棋是目前的主要训练内容，也支持揭棋对弈。

## 第一次使用，从这一轮开始

连接可用服务后，可以先以游客身份体验基础训练：

1. 打开“今日”，完成一组推荐题。
2. 遇到错题，跟随提示重算，之后按提醒复习。
3. 到“对弈”下一盘棋，结束后在“我的棋局”中复盘。
4. 看看“成长报告”，为下一次训练选一个薄弱专项。

需要保留个人训练进度和棋谱时，注册并登录账号。更多操作见[使用指南](docs/USER_GUIDE.md)。

## 在哪里使用

| 方式 | 怎么用 | 目前的情况 |
| --- | --- | --- |
| 浏览器 | 打开服务提供者给出的网址，电脑和手机均可访问；浏览器支持时可添加到桌面 | 支持自行部署体验，官方体验网站尚未开放 |
| Windows 客户端 | 安装后打开，使用随客户端预设的服务；想加强本机棋力时，可在设置中下载安装象棋引擎 | 已有客户端实现，正式安装包尚未发布 |
| Android 客户端 | 安装应用后连接服务，在手机上训练和对弈 | 仍在开发与设备验证阶段，尚未正式发布 |

客户端需要连接服务才能使用账号、题库和训练记录。日常使用无需自己搭建服务器；目前尚无官方服务，可连接自行部署的实例。

## 账号、收费与自己的服务器

**收费计划。** 计划让客户端免费使用，收费重点放在官方托管服务与 AI 讲解额度。当前尚未开放付费购买，正式套餐、价格和权益会在上线前公布。

**AI 讲解按需使用。** 基础训练与规则教练不要求开启 AI。AI 讲解由所连接的服务提供，需要登录并有可用额度；可在“设置 → 账户与 AI 额度”查看。训练奖励积分和 AI 额度分别计算。

**支持自己的服务器。**在“设置 → 服务器（高级）”连接自建服务，也可恢复客户端的默认服务。不同服务器的账号、训练记录和棋谱各自独立，切换不会自动搬迁数据。操作步骤见[使用指南](docs/USER_GUIDE.md#连接自己的服务器)。
