## 追加：题库导入与管理

在原四批基础上增加 GitHub／本地标准 JSON 导入、固定上游提交、快照预览、合法性检查、重复与题解冲突报告、导入待审核、批量发布／下架、编辑与来源导出。Wukong、CCPD 沿用各自的离线转换器，新增拆批工具，不执行上游脚本，也不把完整对局自动视为题目。

旧题默认维持已发布，学习记录与私人错题保留；修复随机生成器的棋子数量限制，移除 5 道三辆红车的种子题，迁移时将对应旧题下架。后台长任务求解与定时同步仍待后续实现；反馈和版本修订已在下一轮补齐。详见[题库导入与管理](development/puzzles.md)。

本轮验证：后端 182 项测试通过（含真实 PostgreSQL 旧版本升级、不同批次并发导入与同批重试）；前端原有 47 项核心、4 项配置测试通过；Web／PC／Android 前端资源构建通过。真实后端 Chromium 验证上传、预览、编辑、发布、导出、下架及移动布局，并实测 GitHub 分支解析与固定提交文件读取。详细内容见[题库质量基线](development/puzzle-quality-baseline.md)。

## 追加：反馈、审核与题解版本

已增加训练页题目反馈、用户独立的反馈与回复列表、管理员处理队列、分支逐手棋盘、绑定内容快照的人工审核记录，以及题解版本链。修订版先待审核，通过审核再原子发布、下架旧版；作答、复习、会话和棋局引用保留。旧版不能重新发布，回退通过新增修订完成。

题目内容变更会使人工审核失效；并发修订、重复审核和驳回／发布竞争均有 PostgreSQL 回归覆盖。本轮后端回归与新增用例共 197 项通过，前端 47 项核心及 4 项配置测试通过，三端前端资源构建通过；真实后端 Chromium 验证多解反馈、审核修订发布、回复查看、移动布局与旧会话提示。详情见[反馈、人工审核与版本修订](development/puzzle-quality.md)。自动多解证明、后台求解、定时同步与反馈推送尚未实现。
