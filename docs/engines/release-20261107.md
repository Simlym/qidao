## 现有 Docker 网站更新

服务器上更新应用代码并重新构建前端即可，**无需上传引擎 ZIP，也无需配置引擎目录挂载或下载代理**：

```bash
git pull --ff-only
docker compose up -d --build frontend
```

若服务器当前有未提交修改，先按现有运维流程合并代码。更新后重新打开网页，在对应引擎设置中点击“下载并启用”。
部署机器仍需保持多线程 WASM 所需的 COOP／COEP 响应头；单线程版可在无共享内存环境使用。
没有服务器访问凭据，本次没有操作线上容器或声称实际业务网站已升级。
