# 象棋道使用指南

本指南面向已经打开象棋道网站或客户端的用户。目前官方服务与正式安装包尚未发布；自行运行项目请看[部署文档](deployment/backend.md)。项目介绍和各端状态见[首页](../README.md)。

## 先体验，再建立自己的训练记录

连接可用服务后，可以用游客身份完成基础训练。想保存独立的训练进度、棋谱和教练计划，请注册并登录账号。AI 讲解需要登录，是否开启及可用额度取决于所连接的服务。

建议先完成“今日”中的一组题，再去“对弈”下一盘棋。之后回到“我的棋局”复盘，并在“成长报告”查看薄弱类目。

## 做题与复习

- “今日”会安排新题和到期复习，适合日常训练。
- “训练”可按类目选择专项，集中练习某种杀法或阶段。
- 遇到难题可以逐级查看提示，再尝试自己算出后续着法。
- 复习时间随作答表现调整；按到期安排重练，有助于巩固容易忘记的棋形。

## 对弈与复盘

在“对弈”中选择先后手和难度，与电脑下一盘棋。对局支持提示、评估、悔棋和棋谱保存。结束后在“我的棋局”查看分析，把关键漏着转成个人练习题。

对弈和分析的棋力取决于当前可用的引擎。标准象棋和揭棋使用不同的引擎设置，普通象棋引擎不能直接用于揭棋。

## 想使用更强的本机引擎

引擎负责计算着法和评价局面，与生成文字讲解的 AI 教练是两项不同能力。客户端安装包不附带第三方引擎。

### Windows

Windows x64 客户端可按以下步骤安装标准象棋引擎：

1. 打开“设置 → 标准象棋引擎”。
2. 点击“从 GitHub 安装并启用”，等待下载和检测完成。
3. 成功后即可使用；下载失败或取消时，原有设置会保留。

当前默认下载 Fairy-Stockfish，无需另找评估权重。若无法访问 GitHub，可以稍后重试，也可以自行取得兼容引擎后手动导入。揭棋仍需单独导入兼容引擎。

### 浏览器与 Android

在引擎设置中导入兼容的浏览器引擎包，选择解压后的整个目录；Windows 的引擎程序不能用于手机或浏览器。文件保存在当前设备，不上传服务器。未导入或加载失败时，使用服务端可用的能力。

其他引擎的来源、兼容格式与许可说明见[引擎文档](engines/README.md)。本机引擎可以提供计算能力，账号、题库和训练记录仍需要连接服务。

## AI 讲解、积分和额度

未开启 AI 时，基于训练统计的画像和学习建议仍然可用。服务开启 AI 后，可提供训练题讲解、失误分析和整局复盘报告等功能。

在“设置 → 账户与 AI 额度”中查看月度额度、补充额度和调用记录。Pro 也有使用上限，以所连接服务显示的策略为准。调用失败会退回预留额度，长时间未完成的请求需等待系统回收。

训练积分用于训练奖励与外观兑换，不抵扣 AI 调用。当前尚未接入支付，开发版额度不代表正式套餐。

## 管理员维护题库

管理员可在“后台 → 题库”导入文件或 GitHub 上的标准题库 JSON，先检查、导入待审核，再发布给用户训练。下架题目会保留学习历史。来源、格式与转换步骤见[题库导入与管理](development/puzzles.md)。

## 连接自己的服务器

大多数用户保留客户端默认服务即可。当前官方服务尚未开放，自行构建的客户端需由发布者预设可用地址。

如果你已经拥有自建服务，或服务提供者给了你连接地址：

1. 先保存正在进行的棋局。
2. 打开“设置 → 服务器（高级）”，输入服务提供者给出的完整地址。
3. 点击“检测连接”；通过后点击“连接并重新加载”。
4. 想返回客户端预设的服务时，点击“恢复默认服务器”。

仅连接你信任的服务。切换会重新加载页面；不同服务器的账号与数据相互独立，不会自动迁移。返回原服务后可继续使用原有登录信息。本机引擎与外观设置仍保留在当前设备。

需要自己搭建服务，请看[后端部署](deployment/backend.md)；地址格式与连接故障排查见[客户端配置文档](development/build-clients.md#在应用内连接自建服务)。
